# პრეზიდენტების რუკა (Presidents Map)

საიტი, სადაც ქვეყანა იჩუქება ერთი დღით: მიმღები იმ დღეს ამ ქვეყნის სიმბოლური მმართველია,
იღებს სერტიფიკატს საკუთარი ბმულით, ნიშნავს მთავრობას, და სხვებს შეუძლიათ გადატრიალების მოწყობა.
მუშაობს ქართულად და ინგლისურად.

## გაშვება

```bash
cd PresidentsMap
dotnet run
```

მონაცემები ინახება SQLite ფაილში `presidents.db`. ბაზა და მისი განახლებები (მიგრაციები) გაშვებისას თვითონ სრულდება.

ტესტები:

```bash
dotnet test PresidentsMap.Tests
```

## პარამეტრები

ყველა პარამეტრი გადაეცემა გარემოს ცვლადით. საიდუმლო მნიშვნელობები არასდროს ჩაწერო `appsettings.json`-ში.

| ცვლადი | რისთვის |
| --- | --- |
| `Site__Url` | საიტის მისამართი (მაგ. `https://presidentsmap.com`); წერილებში და გაზიარების ბმულებში იწერება |
| `ConnectionStrings__Default` | ბაზის ფაილი, მაგ. `Data Source=/data/presidents.db` |
| `PayPal__ClientId`, `PayPal__Secret` | PayPal-ის გასაღებები; მათ გარეშე გადახდა სიმულაციაა |
| `PayPal__Sandbox` | `true` სატესტო რეჟიმი (ნაგულისხმევი), `false` რეალური ფული |
| `Smtp__Host`, `Smtp__Port`, `Smtp__User`, `Smtp__Password`, `Smtp__From` | ფოსტის სერვერი; მის გარეშე წერილები მხოლოდ ლოგში იწერება |
| `Admin__Key` | ადმინის გვერდის გასაღები (`/admin.html`); მის გარეშე ადმინი გამორთულია |

## წერილები

- **ქვითარი** მყიდველს, სერტიფიკატის ბმულით.
- **„ჩამოგაგდეს“** წინა მყიდველს, დაბრუნების ფასით და ბმულით.
- **სერტიფიკატის მიწოდება** მიმღებს საჩუქრის დღეს (00:00 UTC-დან, მოწმდება 5 წუთში ერთხელ).

ელფოსტა არასავალდებულოა და საჯაროდ არსად ჩანს.

## ადმინი

`/admin.html` აჩვენებს მდგომარეობას (გადახდის რეჟიმი, წერილები, საიტის მისამართი), სატესტო წერილის ღილაკს
და ბოლო 200 საჩუქარს ელფოსტებით და შემოსავლით. შეიძლება მილოცვის წაშლა,
სკამის წაშლა და მთლიანი საჩუქრის წაშლა (დღე თავისუფლდება). თანხა ავტომატურად არ ბრუნდება.

## Docker

საჭიროა მხოლოდ Docker. `PresidentsMap` საქაღალდეში:

```bash
docker compose up -d --build
```

საიტი იხსნება მისამართზე http://localhost:8080, დემო რეჟიმში. ბაზა ინახება Docker-ის მუდმივ დისკზე (`data`),
ამიტომ ხელახალი აწყობისას მონაცემები რჩება.

პარამეტრებისთვის დააკოპირე `.env.example` ფაილად `.env`, შეავსე საჭირო ველები და თავიდან გაუშვი იგივე ბრძანება.
`.env` ფაილი რეპოზიტორიაში არ იტვირთება.

| ბრძანება | რას აკეთებს |
| --- | --- |
| `docker compose logs -f` | ლოგების ნახვა |
| `docker compose down` | გაჩერება (მონაცემები რჩება) |
| `docker compose down -v` | გაჩერება და ბაზის წაშლა |

### სერვერზე გამოქვეყნება

საჭიროა ნებისმიერი Linux სერვერი (VPS), რომელზეც Docker დგას, და დომენი, რომლის DNS A ჩანაწერი ამ სერვერის IP-ზე უთითებს.

1. ატვირთე პროექტი სერვერზე (`git clone` ან zip).
2. `PresidentsMap` საქაღალდეში დააკოპირე `.env.example` ფაილად `.env` და შეავსე: `DOMAIN`, `SITE_URL` (მაგ. `https://შენი-დომენი`), `ADMIN_KEY`, ფოსტის და გადახდის ველები.
3. გაუშვი:

```bash
docker compose --profile https up -d --build
```

HTTPS სერტიფიკატს Caddy თვითონ იღებს და ანახლებს. სერვერზე ღია უნდა იყოს 80 და 443 პორტები.

შემდეგ გახსენი `https://შენი-დომენი/admin.html`, შედი `ADMIN_KEY`-ით და ნახე მდგომარეობა: გადახდის რეჟიმი, წერილები, საიტის მისამართი.
იქვე არის „სატესტო წერილის გაგზავნა“, რომელიც ფოსტის პარამეტრებს ამოწმებს.

განახლება: ახალი კოდის ატვირთვის შემდეგ იგივე ბრძანება. ბაზის სარეზერვო ასლი:

```bash
docker compose cp web:/data/presidents.db ./backup.db
```

## გაშვებამდე შესავსები

- `wwwroot/legal.html`: ოპერატორის სახელი, ქვეყანა, საკონტაქტო ელფოსტა, თარიღი (კვადრატულ ფრჩხილებშია). ტექსტი მონახაზია და იურისტმა უნდა ნახოს.
- გადახდის ანგარიში, რომელსაც თანხის მიღება შეუძლია.
- ფოსტის სერვერი (ნებისმიერი SMTP სერვისი).
- დომენი და ჰოსტინგი.
