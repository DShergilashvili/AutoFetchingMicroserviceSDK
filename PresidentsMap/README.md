# პრეზიდენტების რუკა (Presidents Map)

საიტი, სადაც ქვეყანა იჩუქება ერთი დღით: მიმღები იმ დღეს ამ ქვეყნის სიმბოლური მმართველია,
იღებს სერტიფიკატს საკუთარი ბმულით, ნიშნავს მთავრობას, და სხვებს შეუძლიათ გადატრიალების მოწყობა.
მუშაობს ქართულად და ინგლისურად.

## გაშვება

```bash
cd PresidentsMap
dotnet run
```

მონაცემები ინახება SQLite ფაილში `presidents.db`. ბაზა და მისი განახლებები (მიგრაციები) გაშვებისას თვითონ სრულდება.

ტესტები:

```bash
dotnet test PresidentsMap.Tests
```

## პარამეტრები

ყველა პარამეტრი გადაეცემა გარემოს ცვლადით. საიდუმლო მნიშვნელობები არასდროს ჩაწერო `appsettings.json`-ში.

| ცვლადი | რისთვის |
| --- | --- |
| `Site__Url` | საიტის მისამართი (მაგ. `https://presidentsmap.com`); წერილებში და გაზიარების ბმულებში იწერება |
| `ConnectionStrings__Default` | ბაზის ფაილი, მაგ. `Data Source=/data/presidents.db` |
| `PayPal__ClientId`, `PayPal__Secret` | PayPal-ის გასაღებები; მათ გარეშე გადახდა სიმულაციაა |
| `PayPal__Sandbox` | `true` სატესტო რეჟიმი (ნაგულისხმევი), `false` რეალური ფული |
| `Smtp__Host`, `Smtp__Port`, `Smtp__User`, `Smtp__Password`, `Smtp__From` | ფოსტის სერვერი; მის გარეშე წერილები მხოლოდ ლოგში იწერება |
| `Admin__Key` | ადმინის გვერდის გასაღები (`/admin.html`); მის გარეშე ადმინი გამორთულია |

## წერილები

- **ქვითარი** მყიდველს, სერტიფიკატის ბმულით.
- **„ჩამოგაგდეს“** წინა მყიდველს, დაბრუნების ფასით და ბმულით.
- **სერტიფიკატის მიწოდება** მიმღებს საჩუქრის დღეს (00:00 UTC-დან, მოწმდება 5 წუთში ერთხელ).

ელფოსტა არასავალდებულოა და საჯაროდ არსად ჩანს.

## ადმინი

`/admin.html` აჩვენებს ბოლო 200 საჩუქარს ელფოსტებით და შემოსავლით. შეიძლება მილოცვის წაშლა,
სკამის წაშლა და მთლიანი საჩუქრის წაშლა (დღე თავისუფლდება). თანხა ავტომატურად არ ბრუნდება.

## გამოქვეყნება

`Dockerfile` მზადაა. ბაზა ინახება `/data`-ში, ამიტომ იქ მუდმივი დისკი უნდა მიაბა.

```bash
docker build -t presidents-map PresidentsMap
docker run -p 8080:8080 -v presidents-data:/data -e Site__Url=https://შენი-დომენი presidents-map
```

საიტი უნდა იდგეს HTTPS-ის მქონე პროქსის უკან (Cloudflare, Caddy, nginx). `X-Forwarded-*` სათაურებს ის თვითონ კითხულობს.

## გაშვებამდე შესავსები

- `wwwroot/legal.html`: ოპერატორის სახელი, ქვეყანა, საკონტაქტო ელფოსტა, თარიღი (კვადრატულ ფრჩხილებშია). ტექსტი მონახაზია და იურისტმა უნდა ნახოს.
- გადახდის ანგარიში, რომელსაც თანხის მიღება შეუძლია.
- ფოსტის სერვერი (ნებისმიერი SMTP სერვისი).
- დომენი და ჰოსტინგი.
