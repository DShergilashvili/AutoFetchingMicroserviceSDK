# პრეზიდენტების რუკა

საიტი, სადაც ქვეყანა იჩუქება ერთი დღით: მიმღები იმ დღეს ამ ქვეყნის სიმბოლური პრეზიდენტია
და იღებს სერტიფიკატს საკუთარი ბმულით.

## გაშვება

```bash
cd PresidentsMap
dotnet run
```

საიტი იხსნება კონსოლში ნაჩვენებ მისამართზე. მონაცემები ინახება ლოკალურ SQLite ფაილში
`presidents.db`, რომელიც პირველ გაშვებაზე თვითონ იქმნება.

## როგორ არის აწყობილი

| ფაილი | რას აკეთებს |
| --- | --- |
| `Program.cs` | API და გვერდების მისამართები |
| `Gift.cs` | ბაზის ცხრილი. ერთი ქვეყანა ერთ დღეს ერთხელ იყიდება (უნიკალური ინდექსი) |
| `Catalog.cs` | ქვეყნები, ფასები, სადღესასწაულო დღეები, მთავრობის თანამდებობები |
| `Payments.cs` | გადახდა. ახლა `DemoPaymentGateway` ყველაფერს ამტკიცებს და თანხას არ ჭრის |
| `CertificatePage.cs` | სერტიფიკატის გვერდი `/cert/{id}` გაზიარების ჩანაწერებით |
| `CardRenderer.cs` | გაზიარების სურათი `/cert/{id}/card.png` |
| `wwwroot/cert.js` | მთავრობა სერტიფიკატის გვერდზე: დანიშვნა, სრული მთავრობის ყიდვა, სკამის წართმევა |
| `wwwroot/` | რუკის გვერდი და `data/countries.json` (ქვეყნების კონტურები, სახელები, საწყისი ფასები) |

რეალური გადახდის დასამატებლად საკმარისია `IPaymentGateway`-ის ახალი იმპლემენტაცია
და მისი რეგისტრაცია `Program.cs`-ში.

## ენები

საიტი ქართულად და ინგლისურად მუშაობს. ენა ირჩევა ბრაუზერის ენით და იცვლება ღილაკით.
სერტიფიკატი და გაზიარების სურათი იმ ენაზეა, რომელზეც საჩუქარი იყიდეს; `?lang=en` ან `?lang=ka` ცვლის.
ქართული ტექსტი კოდში წერია და თვითონ არის გასაღები; ინგლისური თარგმანები დევს `Loc.cs`-ში (სერვერი)
და `wwwroot/i18n.js`-ში (გვერდები).

## შემოსავლის მოდელი

| რა იყიდება | ფასი |
| --- | --- |
| ქვეყანა ერთი დღით | $5–40 ფართობის მიხედვით, სადღესასწაულო დღეებში ორმაგი |
| პრემიერ-მინისტრი | $3 |
| მინისტრი (8 თანამდებობა) | $1 |
| სრული მთავრობა ერთად | დარჩენილი თანამდებობების ჯამი 30%-ით იაფად |
| დაკავებული სკამის წართმევა | სკამის ბოლო ფასი × 1.5, მინიმუმ $1-ით მეტი |

პრეზიდენტობა საჩუქარია და მისი წართმევა არ შეიძლება; გადატრიალება მხოლოდ მთავრობის სკამებზე მოქმედებს.

ბაზის სქემა გაშვებისას იქმნება მხოლოდ მაშინ, როცა ფაილი არ არსებობს. მოდელის შეცვლის შემდეგ
წაშალე `presidents.db` ან გადადი EF Core მიგრაციებზე.
